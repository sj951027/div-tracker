# v1.3 (2026-08-18) 수집 실패 사유 로그 추가

## 변경
- `fetch_rank.py`: 실패 시 Actions 로그에 사유를 한 줄로 구분 출력.
  - `✗ 티커: 가격 이력 없음(재시도 소진)` — 429/빈 차트 응답으로 3회 시도 모두 실패
  - `✗ 티커: 분배금 이력 없음 | 가격 데이터 부족 | 배당률 시계열 250일 미만` — 가격은 왔지만
    analyze() 불가. 야후 응답의 가격 행수·분배금 건수 병기.
- 산식·순위·알림 변경 없음. 로그 전용.

## 이유
2026-08-18 KR 7종 실패의 원인 진단에 소거법이 필요했음 — 코드에 "로그 없이 fails로 가는
경로"(analyze None)가 있어 로그만으로 429와 분배금 구멍을 구분할 수 없었다(실측: 48초 완료·
재시도 0회로 429 기각, 분배금-빈 응답으로 확정). 다음부턴 로그 한 줄로 즉시 판별.

## 영향
- 코드 동작 변화 없음(출력만 추가). 분배금-빈 응답에 대한 재시도는 효과 불확실로 보류 —
  사유 로그로 며칠 관찰 후 필요하면 논의(백로그).

## 검증
- `--selftest` 통과(산식 변화 없음), 구문 검사 통과. 실로그 출력 형태는 다음 실행에서 확인.
